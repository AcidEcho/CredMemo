## 浏览器设置限制

- “固定到工具栏”由 Chrome 版本、用户设置或策略控制，插件没有取消固定的接口，无法强制保证每次安装默认关闭。需要在扩展详情中关闭“固定到工具栏”或取消图钉。
- Chrome 默认禁止扩展在无痕窗口运行，插件不能替用户开启。首次需到 `chrome://extensions/` → CredMemo →“详情”手动打开“在无痕模式下启用”，按浏览器提示重新加载或重启；授权保存后，无需每次重新允许。
- 普通和无痕窗口共享凭证及解锁状态。无痕中主动保存的凭证会保留在本地，关闭无痕窗口不会删除凭证；重启浏览器需要重新解锁。

## 下载与升级

- ZIP 文件名为 `CredMemo-2.9.0.zip`，解压后仍使用固定的 `CredMemo` 目录。首次加载包含 `manifest.json` 的该目录。
- 现有用户先做加密备份，将新版 `CredMemo/` **里面的文件**覆盖原安装目录，再点击原插件的“重新加载”；保持原目录和浏览器配置，不要先卸载或重复加载新目录。
- 旧主密码、加密凭证和标准备份继续兼容；导入文件若将配置链接直接放在密钥字段中，会被拒绝，需改为密钥或通过网页二维码扫码添加。
- CRX 沿用固定签名，安装仍受 Chrome 与操作系统策略限制。ZIP 与 CRX 的插件身份不同，切换时须通过加密备份迁移。
