## 更新内容

- 继续缩小凭证卡片高度，将编辑、删除和收藏集中到标题旁，仅在存在多组计数或网站填充时保留底栏。
- 卡片增加直接删除按钮，点击后须确认；取消不会修改凭证，点击标题仍可查看详情。
- 移除新建、编辑表单的强密码生成功能和账号标签入口，保留旧凭证已有标签。
- 普通 2FA 不再显示高级参数；导入二维码、输入配置链接或编辑已有特殊配置时，按需显示位数、周期和算法。
- 中文“账号 / 邮箱”统一为“账号”，英文对应改为“Account”。

## 验证情况

- 类型检查、29 项核心测试及 ZIP、固定签名 CRX 打包通过。
- Linux Chrome 浏览器验收覆盖实际工具栏弹窗、紧凑卡片、直接编辑、删除确认与取消、多组凭证、二维码图片和特殊 2FA 配置保留。
- 已检查中文、英文和深浅主题的实际界面；Windows、macOS 尚未真机验收。

## 下载与升级

- 已有 ZIP 用户先导出加密备份，将 `CredMemo-2.7.0.zip` 内部文件覆盖原加载目录，再点击原插件的“重新加载”。不要另建目录加载或先卸载旧版。
- CRX 沿用固定签名，安装受系统和浏览器策略限制；首次从 ZIP 切换到 CRX 需通过加密备份迁移。
- 旧账号标签、2FA 密钥和特殊动态码参数在编辑保存时继续保留。
