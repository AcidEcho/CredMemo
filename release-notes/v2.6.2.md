## 更新内容

- 为 v2.4.1、v2.5.0、v2.5.1、v2.5.2 补齐中文发布说明，分别记录当时的功能、安装方式和验证边界。
- 补充重复安装的排查说明：插件名称为 CredMemo，Chrome 单独显示版本号；不同 ID 的插件拥有独立凭证库。
- 明确 ZIP 必须覆盖原加载目录，即使目录名包含旧版本号也保留；不能通过另建新版目录重复加载完成升级。
- 升级验收增加 v2.5.0 旧包支持，以及不同目录加载会生成独立 ID 和空凭证库的检查。

## 验证情况

- 类型检查、29 项核心测试及 ZIP、固定签名 CRX 打包通过。
- 使用已发布的 v2.5.0 安装包，在 Linux Chrome 验证原目录升级后 ID、加密凭证、旧长主密码、2FA 和备份保持可用，重启后数据保留。
- 已验证从另一个目录加载相同新版会生成不同 ID 的独立安装，原凭证仍保留在原插件中。
- 本次未修改插件界面，未重复完整界面验收；Windows、macOS 的安装升级尚未真机验收。

## 下载与升级

- 已有 ZIP 用户先导出备份，将 `CredMemo-2.6.2.zip` 内的文件覆盖原目录，再点击原插件的“重新加载”。
- 如果已经出现两个 CredMemo，先分别备份其中需要保留的数据，再选择保留的一份按原目录升级；不同凭证库不会自动合并。
- CRX 沿用固定签名，安装受浏览器策略限制；首次从 ZIP 切换到 CRX 需通过加密备份迁移。
