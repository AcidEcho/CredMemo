## 更新内容

- 新建凭证默认依次显示名称、账号、密码、2FA、备注，五项及保存按钮同屏可见。
- 默认账号、密码和 2FA 输入框固定保留；额外添加的账号和 2FA 条目仍可移除。
- 2FA 字段标题简化为“2FA”，仍支持密钥或配置链接。
- 网站、标签、多组条目、二维码图片和动态码参数收进“更多选项”。
- 凭证卡片的密码行补充图标，增加直接编辑按钮，并缩小卡片高度。
- Release 同时提供 ZIP 和固定签名的 CRX3 安装包，后续 CRX 沿用同一插件身份。

## 验证情况

- 类型检查和 29 项核心测试通过。
- 5 套浏览器验收通过，覆盖凭证管理、网页填充、二维码识别、网页框选和覆盖升级。
- 已检查中文、英文、深色主题和较矮屏幕下的真实弹窗布局。
- 线上 ZIP、CRX 的校验值、许可证、CRX 签名和包内内容已核验。
- 浏览器验收使用 Linux Chrome；Windows、macOS 的 CRX 安装及覆盖更新尚未真机验收。

## 下载与升级

- 推荐现有 ZIP 用户下载 `CredMemo-2.6.0.zip`，备份后覆盖原安装目录，在扩展页面点击“重新加载”。不要先卸载旧版。
- `CredMemo-2.6.0.crx` 能否直接安装取决于系统和浏览器策略；安装被拒绝时可使用 ZIP。
- 首次从 ZIP 切换到 CRX 会使用不同的插件身份，需先导出加密备份，再在 CRX 版本中恢复，原凭证不会自动迁移。
