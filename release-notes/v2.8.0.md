## 更新内容

- 插件弹窗宽度由 390px 收窄至 360px，默认表单和保存按钮保持同屏可见。
- 新建、编辑凭证依次展示名称、网站地址、账号、密码、2FA、备注；网站地址移至名称下方。
- 2FA 输入提示简化为“输入 2FA 密钥”，输入框旁增加扫码按钮。点击后直接在当前网页框选二维码，识别后回到原表单，保留已填内容并回填密钥和动态码参数，点击“保存”才创建或更新凭证。
- 取消扫码恢复原草稿；草稿可跨扩展后台休眠恢复，仅保存在浏览器会话内存，锁定时清除。修复自动重开弹窗后，后台焦点窗口不明确导致再次扫码失败的问题。
- 移除“更多选项”“添加账号”“添加 2FA”“从图片识别”入口及对应操作逻辑；旧凭证、备份中的多组账号、2FA、标签、收藏和特殊动态码参数继续保留。
- 下载文件名保留版本号，ZIP 内统一使用固定顶层目录 `CredMemo/`。CRX 使用相同文件单独打包，保持入口位于根目录和原有固定签名。

## 下载与升级

- 首次 ZIP 安装：解压 `CredMemo-2.8.0.zip`，在 Chrome 开发者模式中加载其中的 `CredMemo` 文件夹，该文件夹直接包含 `manifest.json`。
- 已有 ZIP 用户：先导出加密备份，将新版 ZIP 中 `CredMemo/` **里面的文件**覆盖原加载目录，再点击原插件的“重新加载”。原目录即使含旧版本号也不要改名，不要在其中再嵌套一层 `CredMemo`，不要先卸载旧版。
- ZIP 内目录固定为 `CredMemo`；部分解压工具可能另套一层版本目录，加载时选择里面直接含 `manifest.json` 的 `CredMemo`。
- CRX 沿用固定签名，安装仍受 Chrome 和操作系统策略限制；普通 Windows、macOS Chrome 可能禁用商店外 CRX。ZIP 切换到 CRX 时需通过加密备份迁移，不能自动合并不同插件 ID 的数据。
