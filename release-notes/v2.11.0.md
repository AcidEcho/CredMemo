## 更新说明

- 移除列表的“全部凭证”标题和网站筛选入口，默认显示全部凭证。
- 搜索改为与新建、扫码并排的图标按钮，点击展开；支持 `/` 快捷打开，按 Esc 或关闭按钮清空并收起。
- 重排导入与备份弹窗：三项切换、紧凑文件选择区、清晰的密码输入区及统一操作按钮，适配中英文和浅深主题。
- 未选择有效文件时禁用导入，切换文件或面板时清理过期状态；正常的备份、恢复和导入导出行为保留。

已通过 44 项核心测试及 8 组浏览器验收，覆盖搜索、排序、备份恢复、扫码回填、网站填充、无痕窗口和原目录覆盖升级。浏览器验收在 Linux Chromium 上完成，Windows、macOS 尚未实测。
