## 更新内容

- 发布纯本地 Chrome 凭证管理插件，无需服务端、数据库或云端账号。
- 支持单独保存账号密码、单独保存 2FA，或组合保存；每条凭证支持多组账号和动态码。
- 支持输入 TOTP 密钥、导入二维码图片，以及选择屏幕、应用窗口或标签页后框选二维码。
- 提供网站填充、一键复制、搜索、收藏、中英文和多主题。
- 提供本地加密存储、加密备份恢复及 JSON 导入导出。
- 补充 README、许可证、分发声明及 GitHub 自动发布流程。

## 下载与升级

- 本版本提供 `CredMemo-2.4.1.zip`，首次使用时通过 Chrome 开发者模式加载解压目录。
- ZIP 升级需先备份，再将新版文件覆盖到原加载目录并点击“重新加载”；另建目录加载会形成独立安装。
- 本版本新建主密码要求 12～256 个字符；屏幕截图受系统和浏览器权限限制。
- 本版本仍使用选择来源的屏幕扫码流程；从 v2.5.0 起改为仅在当前网页直接框选。
