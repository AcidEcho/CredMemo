## 更新内容

- 合并账号密码、两步验证和组合凭证的创建入口，统一按填写内容保存，无需先选类型。
- 移除分类入口，凭证统一展示，保留搜索和收藏。
- 点击扫码后直接在当前网页框选二维码，识别成功自动保存；取消来源选择器和独立扫码窗口。
- 扫码范围调整为当前网页可见区域，保留本地二维码图片识别。
- 安装说明改为从扩展菜单打开，工具栏固定状态由 Chrome 和用户管理。

## 下载与升级

- 本版本提供 `CredMemo-2.5.0.zip`；更新前导出加密备份，再覆盖原加载目录并点击“重新加载”。
- 不要为新版另建目录重复加载，否则 Chrome 会创建不同 ID 的独立插件和凭证库。
- 本版本新建主密码要求 12～256 个字符；网页扫码不再截取其他应用或桌面。
